Architecture

Studio IDE (Mcaster1InstallStudio)

StudioMainWindow
  ├── ProjectSidebar         (left nav tree)
  ├── QTabWidget (9 tabs)
  │   ├── AppInfoEditor      (app metadata + defaults + theme)
  │   ├── FilesEditor        (components + files)
  │   ├── ComponentsEditor   (deps + flags)
  │   ├── ShortcutsEditor    (shortcuts table)
  │   ├── RegistryEditor     (registry entries)
  │   ├── SecurityEditor     (signing credentials)
  │   ├── PrerequisitesEditor(prereq list+form)
  │   ├── CustomActionsEditor(actions table)
  │   └── BuildPanel         (build + test)
  ├── BuildLog dock          (QPlainTextEdit)
  └── StatusBar              (status + clock)

Runtime Installer (Mcaster1Installer)

InstallerWizard (QWizard)
  ├── WelcomePage     (PageId 0)
  ├── LicensePage     (PageId 1)
  ├── PrerequisitesPage (PageId 2, conditional)
  ├── ComponentsPage  (PageId 3)
  ├── DirectoryPage   (PageId 4)
  ├── ReadyPage       (PageId 5)
  ├── InstallPage     (PageId 6)
  │   └── InstallEngine (QThread)
  └── FinishPage      (PageId 7)

Manifest data flow:
  .mis file → InstallerWizard → pages read manifest()
  Components → selectedComponents → InstallEngine
  InstallEngine → copies files, creates shortcuts,
                  writes registry, runs custom actions,
                  writes uninstall manifest
