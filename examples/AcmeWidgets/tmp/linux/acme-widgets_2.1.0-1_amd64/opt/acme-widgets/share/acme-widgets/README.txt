ACME Widgets 2.1.0
==================

Thank you for installing Acme Widgets — the cross-platform widget toolkit
from ACME Corporation.

QUICK START
-----------
After installation, run the following command to get started:

    acme-widgets --help

For a full list of available commands:

    acme-widgets list         — list all configured widgets
    acme-widgets start        — start the widget service
    acme-widgets stop         — stop the widget service
    acme-widgets status       — show service status
    acme-widgets config       — display current configuration
    acme-widgets version      — show version information

CONFIGURATION
-------------
The default configuration file is installed to:

  macOS / Linux:  {install-dir}/etc/acme-widgets.conf
  Windows:        {install-dir}\etc\acme-widgets.conf

User-specific overrides can be placed in:

  macOS / Linux:  ~/.acme-widgets/acme-widgets.conf
  Windows:        %APPDATA%\ACME Corporation\acme-widgets.conf
