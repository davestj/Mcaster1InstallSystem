Welcome to Acme Widgets 2.1.0

This installer will guide you through installing Acme Widgets from ACME Corporation on your Mac.

Acme Widgets is a cross-platform widget toolkit for managing and deploying ACME products. This release includes the widget runtime, default configuration, and documentation.

This is an example installer created with the Mcaster1 Install System. The application binaries are demonstration stubs — no real services are started.
